# BMS Cell Emulator V1
These are the KiCad PCB files relating to Nathan Christiansen's V1 for a PCB designed to emulate 
the battery cells of an individual module. With something similar to this we can test the Cell Monitor PCBs 
and the Main Control Unit for the BMS without the need to plug those PCBs into the battery first. We can
safely test those different parts of the BMS before we plug them into live battery cells.
