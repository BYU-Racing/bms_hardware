# BMS Flex PCBs (FPCs) V1 Files

This was originally intended to be used as the connection from the current collector plates on the modules to the
BMS Cell Monitor PCB V1.01. (in the rules its called the Voltage sense leads)

The idea to use the FPCs was scrapped for the 2027 season due to team integration timeline constraints.
This is still a totally viable and incredibly sleek solution for future years.

The main intent behind using these was as follows:
- instead of using very long tabs on the current collector plates we can solder these very close to the cell stack,
eliminating a lot of risk while manufacturing (because with the long collector plate tabs we have a risk of shorting those tabs to neighboring cells)
- We can have the thermistors soldered directly to the FPC and thus have a closer and better thermal connection to the cells
- Another ease of manufacturing is that we can just lay this across the cells and then solder it and its done.
